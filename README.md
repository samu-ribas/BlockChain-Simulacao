# BlockChain-Simulacao

Este projeto consiste na simulação em linguagem C de uma versão simplificada da blockchain da criptomoeda Bitcoin (BTC).

### Contexto do Projeto
Este projeto é o trabalho final da disciplina de Estruturas de Dados (UTFPR).

O objetivo é simular uma versão simplificada da blockchain do Bitcoin, incluindo a lógica de mineração (SHA-256), transações, carteiras (saldos) e armazenamento eficiente dos blocos minerados.

### Principais Tecnologias e Conceitos

* **Linguagem:** C
* **Algoritmo de Hash:** SHA-256 (via OpenSSL)
* **Estruturas de Dados:** Manipulação de Arquivos Binários e Implementação de Estruturas de Índices eficientes (Nonce e Endereço).

### Instruções de Build e Execução

Para compilar e rodar o projeto, você precisará ter o compilador GCC e as bibliotecas OpenSSL instaladas.
